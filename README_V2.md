# Smartup SCM v2 — готовый GitHub Pages-пакет

Обновлённая демонстрационная версия Smartup SCM на основе финальной Google Sheets-модели (срез 01.10.2026).

## Публикация

1. Скачайте ZIP этой ветки, распакуйте.
2. Скопируйте **содержимое** папки `SmartupSCM-delivery-scm-v2-download` в корень вашего GitHub Pages-репозитория (не саму внешнюю папку).
3. Загрузите **все** файлы, включая `index.html`, `app.js`, `styles.css`, папку `assets`.
4. В репозитории GitHub откройте Settings → Pages; источник публикации — ваша основная ветка, корневая папка.
5. После публикации откройте сайт, нажмите «Сбросить демонстрацию» (при необходимости) и проверьте операции.

## Что изменено

- Сохранены существующие стили, навигация и возможности исходного сайта.
- `assets/scm-v2-data.js`: набор подтверждённых исходных и расчётных значений Google Sheets.
- `assets/scm-v2.js`: обновлённые экраны для исходного сайта — прогноз как входные данные, закупки, распределение, сценарии, согласования, журналы.
- `index.html`: подключены два дополнительных файла после основного `app.js`.
